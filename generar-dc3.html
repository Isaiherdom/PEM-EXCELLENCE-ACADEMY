Constancia de Habilidades Laborales — mismo formato oficial que ya usa PEM, generada a partir de un módulo ya certificado.
Antes de usar este documento de forma oficial: confirma con el área legal/laboral de PEM que ya cuentan con el DC-2 (Plan y Programa de Capacitación) vigente y la Comisión Mixta de Capacitación constituida (obligatoria para PEM por tener más de 50 colaboradores) — ambos son el respaldo legal real detrás de cada DC-3. Este generador no sustituye esa verificación.
