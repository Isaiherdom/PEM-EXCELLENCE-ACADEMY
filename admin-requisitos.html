Administrar requisitos por puesto

Define qué escuelas (normas) debe cursar cada puesto. El Dashboard Ejecutivo usa esto para calcular el % de avance real de cada colaborador y de cada sitio — contra lo que les corresponde, no contra las 4 escuelas completas para todos.
Cargando requisitos…
⚠️
Por default, todos los puestos requieren las 4 escuelas (así se comportaba el Dashboard antes de este panel, para no cambiarte ningún número sin que tú lo decidas). Destilda las escuelas que no le correspondan a cada puesto — por ejemplo, si "Cuentas por Pagar" no necesita Escuela de Seguridad, destíldala en esa fila.
